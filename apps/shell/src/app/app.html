Architecture

This repo is an Nx workspace: Angular frontends plus a Node BFF. CI runs nx affected so a tokens-only change does not pretend to be a backend change. Ops (GitHub + domain checks) will live in a sibling Go repo, not inside this graph.

Weather is fetched through the BFF from Open-Meteo. The browser never holds provider keys.
